# DLD — Backend — Module 005: Showroom Collection Management
## Showroom Application

**Layer:** Backend (Next.js)

---

## 1. Purpose
Empowers **Admin** and **Inventory Manager** to manage their specific showroom's collection:
- Bikes and Cars
- Available Spare Parts
- Showroom profile information

---

## 2. API Endpoints

- `GET /api/admin/collection` — Fetch all vehicles and spare parts for the authenticated Admin's showroom.
- `PUT /api/admin/showroom-profile` — Update showroom address, contact numbers, and operational hours.
